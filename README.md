# הוראות הפעלה – Asset & License Tracker (Web Edition)

אפליקציית Web מודרנית, מעוצבת ורספונסיבית, המממשת במלואה ובנאמנות של 100% את הלוגיקה העסקית של פרויקט ה-CLI (`finalproject05`).

---

## 🌟 מאפייני האפליקציה (Client-Side Only)

* **ללא צד שרת וללא מסד נתונים:** פועלת באמצעות HTML5, CSS3 ו-JavaScript בלבד (Vanilla JS).
* **שמירה מקומית (Persistence):** שימוש ב-`localStorage` לשמירת כל הפעולות (השאלות, החזרות, הוספת פריטים) לאורך זמן בין רענונים של הדפדפן.
* **סנכרון מלא לקובץ `inventory.csv`:** כפתור ייעודי לייצוא והורדה של קובץ ה-CSV המעודכן בכל רגע, כולל תאימות קידוד מלאה.
* **אפשרות שחזור (Reset to Default):** כפתור לשחזור מהיר של 9 הפריטים המקוריים מקובץ ה-CSV ההתחלתי.
* **עיצוב בגווני סגול, שחור ואפור (Regal Violet / Dark Theme):**
  - תמיכה מלאה במצב **Dark Mode** (ברירת מחדל מודרנית עם גווני סגול ניאון, שחור עמוק ואפור).
  - מתג בלחיצה אחת למצב **Light Mode** (גוונים בהירים ונקיים על בסיס סגול).
  - עיצוב RTL מותאם לעברית מלאה.
* **נאמנות לכל 7 האפשרויות של תפריט ה-CLI:**
  1. `[1]` הצגת כל הפריטים בטבלה מפורטת עם חיפוש חופשי וסינון לפי סוג וסטטוס.
  2. `[2]` השאלת ציוד / שיוך רישיון לעובד (עם סינון פריטים זמינים ואזהרת פגי תוקף).
  3. `[3]` החזרת ציוד ועדכון סטטוס (`Available`, `Under Repair`, `Retired`).
  4. `[4]` הפקת דוח פגומים ופגי תוקף (כולל העתקה ללוח והורדה כקובץ `missing_expired_report.txt`).
  5. `[5]` הוספת פריט או רישיון חדש עם זיהוי ID אוטומטי ובחירת תאריך תפוגה.
  6. `[6]` ייצוא וסנכרון CSV.
  7. `[7]` שחזור נתונים מקוריים.

## 🚀 כיצד להפעיל את האפליקציה?

האפליקציה אינה דורשת התקנת Node.js או שרת מקומי. ניתן להפעיל אותה בשתי דרכים:

### דרך 1: פתיחה ישירה בדפדפן (Double Click)
פשוט לחץ לחיצה כפולה על הקובץ:
`c:\QAAUTOMATION\PYTHON\finalproject05\web\index.html`
הוא ייפתח מיד בכל דפדפן (Chrome, Edge, Firefox).

### דרך 2: הרצה כשרת מקומי פשוט (אופציונלי)
אם ברצונך לפתוח דרך Localhost:
```bash
cd c:\QAAUTOMATION\PYTHON\finalproject05\web
python -m http.server 8000
```
ולגלוש לכתובת: `http://localhost:8000`
